# Independent usability evaluation: proposed protocol, not completed

No results, participant counts or adoption claims are available. This document
is a preparation aid for the authors and is not evidence of independent use.

Recruit researchers with clustering experience who did not develop the package.
Agree institutional ethics/consent requirements before collecting participant
data. Keep identities and raw participant records out of the public repository.

Tasks: generate a labelled dataset with unequal groups; generate a paired noise
sweep without changing signal; reproduce one figure from a supplied archive.
Use the same acceptance checks for a package workflow and a supplied competent
NumPy/scikit-learn baseline. Counterbalance task/tool order and record previous
Python, clustering and tool experience. Permit the same documentation access.

Record task completion, invariant violations, assistance requests, active time
and usability comments. Distinguish learning time from execution time. Report
all participants and incomplete tasks. Prespecify primary measures and analysis
before recruitment, and choose sample size to match the intended precision.
Small exploratory samples cannot support broad productivity claims.
